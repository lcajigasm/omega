# Analysis, 2 Nov 2026

Base: `main` at `f0b8041` (formula for v0.11.0). The v0.11.0 tag is the squash `81f3e39`.

v0.11 already refuses disguised wipes, caps command output, and runs a read-only tool batch together. Nothing in the tree is marked TODO. The next gaps are places where a normal run sends something it should not, or waits in a way that wastes the few retries it has.

## Chosen

1. **Private keys and credential files never reach the model.** `read_file` reads any path, up to 64 KB, and returns the bytes as a tool result. `cat`, `head`, `tail` and `grep` of the same path are classified read-only, so they run with no question and under `--yes`. That covers `~/.ssh/id_ed25519`, `~/.aws/credentials`, `~/.netrc`, `~/.config/gh/hosts.yml`, `.env`, and `security find-generic-password -w`. The fix refuses the read and blocks the command. Public keys, `~/.ssh/config`, and `ls ~/.ssh` stay usable. `env | grep ^HOMEBREW_` stays read-only: the pipe split cannot tell that form from a full dump, and the catalogue already depends on it.

2. **`omega doctor` checks the configured model.** Doctor already proves the provider answers, then throws the model list away. A typo in `model`, `fast_model` or `smart_model` is a 404 on the first real chat. When the user set one of those and the provider returned a non-empty list, doctor fails if the name is absent. `auto`, an empty setting, and an empty list do not fail: there is nothing to compare, or the server did not give names.

3. **A 429 waits for `Retry-After`.** Both clients retry on a fixed 2s, then 4s, then 8s, and ignore the header. A server that asks for 12s is hit again too soon, which spends the remaining attempts. The wait is the header when it is a delay in seconds or an HTTP date, capped at 30s so one reply cannot stall the run. A missing or unreadable header keeps the old schedule. The same rule applies to Anthropic and to OpenAI-compatible providers.

The release job also starts `verify-taps` itself. A release created with the workflow token does not start other workflows, which is why the v0.11.0 check never ran until a separate dispatch. That is release plumbing, not a fourth product change.

## Left out

- Measuring `log show --last 30m` needs macOS. This environment is Linux.
- `lcajigasm/homebrew-tap` stops in its updater on ownterm before it reaches omega. That script lives in the tap repository.
- Blocking a bare `env` or `printenv`. See the exception under item 1.
