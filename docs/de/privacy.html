Datenschutz

omega ist ein Kommandozeilen-Tool und eine Desktop-App. Beide laufen auf deinem Rechner. Es gibt kein Konto, keinen eigenen Server, keine Analytik und keine Telemetrie. Diese Website setzt keine Cookies; wenn du eine Sprache wählst, merkt sie sich die Wahl in deinem Browser.

Was auf deinem Rechner bleibt

Deine API-Keys werden im macOS-Schlüsselbund unter dem Dienst omega-cli gespeichert. Unter Windows liegen sie in der Anmeldeinformationsverwaltung. Unter Linux liegen sie im Schlüsselbund des Systems (Secret Service) oder, wenn es keinen gibt, in ~/.config/omega/keys, einer Datei, die nur dein Benutzer lesen kann. Deine Konfiguration liegt in ~/.config/omega/config.toml, die Notizen, die der Agent über deinen Rechner führt, in ~/.config/omega/notes.md, und ein Protokoll jedes Laufs in ~/.local/state/omega/runs. Du kannst alles davon jederzeit löschen.

Was an deinen KI-Anbieter geht

omega spricht nur mit dem Anbieter, den du einrichtest: Anthropic, OpenAI, OpenRouter oder OpenCode Zen. Jede Anfrage enthält die Anweisungen von omega, deine Notizen, die gekürzte Ausgabe der Befehle, die es ausgeführt hat, und den Inhalt der Konfigurationsdateien, die es gelesen hat. Der Agent ist angewiesen, keine persönlichen Dokumente zu lesen. Für diese Anfragen gelten die Datenschutzerklärung und die Aufbewahrungsfristen des jeweiligen Anbieters.

Der Modellkatalog

Um die Modelle des automatischen Modus zu wählen, lädt omega einmal am Tag die öffentliche Modellliste von OpenRouter von openrouter.ai, auch wenn dein Anbieter ein anderer ist. Es ist eine einfache Anfrage ohne Schlüssel und ohne Angaben zu dir oder deinem Rechner; OpenRouter kann deine IP-Adresse protokollieren, wenn es sie beantwortet. omega config set model_catalog off stoppt sie, und lokale Anbieter stellen sie nie.

Die Versionsprüfung

omega doctor fragt GitHub (api.github.com) nach dem Tag des neuesten omega-Release, um dir zu sagen, wenn deines älter ist. Die Anfrage enthält nichts über dich; GitHub kann deine IP-Adresse protokollieren. Kein anderer Befehl stellt sie.

Diese Website

Diese Website wird auf GitHub Pages gehostet und lädt Schriften von Google Fonts und, auf der Startseite, den Sitzungsplayer von jsDelivr. Diese Dienste können deine IP-Adresse protokollieren, wenn sie die Dateien ausliefern.
