Privacidad

omega es una herramienta de línea de comandos y una app de escritorio. Las dos se ejecutan en tu equipo. No tiene cuenta, ni servidor propio, ni analíticas, ni telemetría. Esta web no usa cookies; cuando eliges un idioma, recuerda la elección en tu navegador.

Qué se queda en tu equipo

Tus API keys se guardan en el llavero de macOS, bajo el servicio omega-cli. En Windows se guardan en el Administrador de credenciales. En Linux se guardan en el llavero del sistema (Secret Service) o, cuando no hay ninguno, en ~/.config/omega/keys, un archivo que solo tu usuario puede leer. Tu configuración está en ~/.config/omega/config.toml, las notas que el agente guarda sobre tu equipo en ~/.config/omega/notes.md, y un registro de cada ejecución en ~/.local/state/omega/runs. Puedes borrar cualquiera de ellos cuando quieras.

Qué va a tu proveedor de IA

omega solo habla con el proveedor que configuras: Anthropic, OpenAI, OpenRouter u OpenCode Zen. Cada petición contiene las instrucciones de omega, tus notas, la salida recortada de los comandos que ha ejecutado y el contenido de los archivos de configuración que ha leído. El agente tiene la instrucción de no leer documentos personales. A esas peticiones se les aplican la política de privacidad y las condiciones de retención de datos de ese proveedor.

El catálogo de modelos

Para elegir los modelos del modo automático, omega descarga una vez al día la lista pública de modelos de OpenRouter desde openrouter.ai, también cuando tu proveedor es otro. Es una petición simple, sin clave y sin nada sobre ti ni sobre tu equipo; OpenRouter puede registrar tu dirección IP al servirla. omega config set model_catalog off la desactiva, y los proveedores locales nunca la hacen.

La comprobación de versión

omega doctor pregunta a GitHub (api.github.com) por la etiqueta de la última versión de omega, para avisarte cuando la tuya es anterior. La petición no lleva nada sobre ti; GitHub puede registrar tu dirección IP. Ningún otro comando la hace.

Esta web

Esta web está alojada en GitHub Pages y carga fuentes de Google Fonts y, en la página de inicio, el reproductor de sesiones de jsDelivr. Esos servicios pueden registrar tu dirección IP al servir los archivos.
