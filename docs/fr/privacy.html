Confidentialité

omega est un outil en ligne de commande et une app de bureau. Les deux s'exécutent sur votre machine. Il n'a ni compte, ni serveur propre, ni outil de mesure d'audience, ni télémétrie. Ce site ne dépose aucun cookie ; quand vous choisissez une langue, il retient ce choix dans votre navigateur.

Ce qui reste sur votre machine

Vos clés d'API sont stockées dans le trousseau macOS, sous le service omega-cli. Sous Windows, elles sont stockées dans le Gestionnaire d'identification. Sous Linux, elles sont stockées dans le trousseau du système (Secret Service) ou, s'il n'y en a pas, dans ~/.config/omega/keys, un fichier que seul votre utilisateur peut lire. Votre configuration se trouve dans ~/.config/omega/config.toml, les notes que l'agent garde sur votre machine dans ~/.config/omega/notes.md, et un journal de chaque exécution dans ~/.local/state/omega/runs. Vous pouvez supprimer n'importe lequel à tout moment.

Ce qui part chez votre fournisseur d'IA

omega ne parle qu'au fournisseur que vous configurez : Anthropic, OpenAI, OpenRouter ou OpenCode Zen. Chaque requête contient les instructions d'omega, vos notes, la sortie abrégée des commandes qu'il a exécutées et le contenu des fichiers de configuration qu'il a lus. L'agent a pour consigne de ne pas lire de documents personnels. La politique de confidentialité et les conditions de conservation des données de ce fournisseur s'appliquent à ces requêtes.

Le catalogue de modèles

Pour choisir les modèles du mode automatique, omega télécharge une fois par jour la liste publique de modèles d'OpenRouter depuis openrouter.ai, même si votre fournisseur est un autre. C'est une requête simple, sans clé et sans rien sur vous ni sur votre machine ; OpenRouter peut enregistrer votre adresse IP lorsqu'il y répond. omega config set model_catalog off la désactive, et les fournisseurs locaux ne la font jamais.

La vérification de version

omega doctor demande à GitHub (api.github.com) l'étiquette de la dernière version d'omega, pour vous dire quand la vôtre est plus ancienne. La requête ne contient rien sur vous ; GitHub peut enregistrer votre adresse IP. Aucune autre commande ne la fait.

Ce site

Ce site est hébergé sur GitHub Pages et charge des polices depuis Google Fonts, des icônes depuis unpkg et, sur la page d'accueil, le lecteur de session depuis jsDelivr. Ces services peuvent enregistrer votre adresse IP lorsqu'ils servent les fichiers.

Contact

Questions ou remarques : ouvrez un ticket sur github.com/lcajigasm/omega/issues.
