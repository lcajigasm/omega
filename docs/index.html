Running topgrade and Mole by hand

  • A step fails and the run moves on with a red line you have to scroll back to
  • You search the error, edit topgrade.toml and launch everything again
  • A cask asks for a password halfway through and the run hangs
  • The same pipx failure comes back next month

Running omega

  • It reads the failure the moment it happens and works out the cause
  • It applies the smallest fix, retries once and moves on if it still fails
  • Commands run without a prompt, so nothing waits on a password you cannot see
  • It writes down what it learned and starts there next time

Your Mac stays current and clean. You only step in when something could be lost.

What changes when an agent runs your maintenance

Failures get fixed, not just reported

omega reads the output, checks the config file behind it and retries with the fix. Your run ends with a summary, not a wall of red.

Nothing risky runs without you

Every command is classified before it runs. Deletes, sudo and config edits wait for your yes. The truly destructive ones never run at all.

It remembers your machine

When it finds out why a step fails on your Mac, it saves a note. The next run starts with that knowledge instead of rediscovering it.

Use the model you already pay for

Anthropic, OpenAI, OpenRouter or OpenCode Zen. Bring one API key, pick any model with tool calling and switch whenever you like.

Space back, measured first

It checks what is actually taking up room before it cleans, then goes after caches, old Homebrew versions, Xcode build data and Docker leftovers.

In your language

The interface and the agent speak English, Spanish, French, German and Portuguese, following your system locale.

Running in three commands

  1. 1

    Install and connect a model

    The setup asks for your provider, stores the key in the macOS Keychain and lets you pick a model.

    brew install lcajigasm/omega/omega
omega setup
  2. 2

    Get a report first

    Analyze mode is read only. You see disk usage, outdated software and config problems before anything changes.

    omega analyze
  3. 3

    Let it do the maintenance

    Updates, cleanup and a summary, with your approval on anything risky. Or ask for something specific.

    omega
omega -p "topgrade fails on rustup, fix it"

Questions

Does omega replace topgrade and Mole?

For a typical developer Mac, yes. omega has its own steps for Homebrew, the Mac App Store, npm, pnpm, bun, pipx, uv, rustup, cargo, gh extensions, Oh My Zsh, macOS, caches, Xcode, Docker and the Trash. If topgrade or Mole are installed, it also uses them and can fix their configuration with omega fix.

What does omega send to the AI provider?

Its instructions, the trimmed output of the commands it runs and the configuration files it reads. It is instructed never to open your documents. Every run is logged to ~/.local/state/omega/runs so you can check exactly what happened.

Can omega delete my files?

Only after you approve it. Deleting, sudo, editing config files and any unknown command need your confirmation. Commands like rm -rf ~, diskutil erase or curl piped into a shell are blocked and never run, even with --yes.

Which AI models work with omega?

Any model with tool calling from Anthropic, OpenAI, OpenRouter or OpenCode Zen. The default is Claude Opus 5.5. List what your provider offers with omega models.

How much does a run cost?

It depends on the model and on how much needs fixing. omega prints the tokens used at the end of every run. Lower the effort setting or pick a smaller model for routine updates.

Can omega run unattended?

Yes. Run omega update --yes --no-tui --once from launchd or cron. Blocked commands stay blocked, and disabled steps stay disabled.

Where are my API keys stored?

In the macOS Keychain, under the service omega-cli. Environment variables such as ANTHROPIC_API_KEY take precedence when set.

Which languages does the interface support?

English, Spanish, French, German and Portuguese. omega follows your system locale, and you can override it with omega config set language. The agent replies in the same language.

Start with a report that changes nothing

Free and open source under the MIT license. omega analyze is read only, so you can see what it would do before you let it do anything.
