Privacy

omega is a command line tool and a desktop app. Both run on your machine. It has no account, no server of its own, no analytics and no telemetry. This website sets no cookies; when you pick a language, it remembers the choice in your browser.

What stays on your machine

Your API keys are stored in the macOS Keychain under the service omega-cli. On Windows they are stored in the Credential Manager. On Linux they are stored in the system keyring (Secret Service) or, when there is none, in ~/.config/omega/keys, a file only your user can read. Your configuration lives in ~/.config/omega/config.toml, the notes the agent keeps about your machine in ~/.config/omega/notes.md, and a log of every run in ~/.local/state/omega/runs. You can delete any of them at any time.

What goes to your AI provider

omega talks only to the provider you configure: Anthropic, OpenAI, OpenRouter or OpenCode Zen. Each request contains omega's instructions, your notes, the trimmed output of the commands it ran and the contents of the configuration files it read. The agent is instructed not to read personal documents. That provider's own privacy policy and data retention terms apply to those requests.

The model catalogue

To choose the models of automatic mode, omega downloads OpenRouter's public model list from openrouter.ai once a day, also when your provider is another one. It is a plain request with no key and nothing about you or your machine in it; OpenRouter may log your IP address as part of serving it. omega config set model_catalog off stops it, and local providers never make it.

The version check

omega doctor asks GitHub (api.github.com) for the tag of the latest omega release, to tell you when yours is older. The request carries nothing about you; GitHub may log your IP address. No other command makes it.

This website

This site is hosted on GitHub Pages and loads fonts from Google Fonts and, on the home page, the session player from jsDelivr. Those services may log your IP address as part of serving the files.

Contact

Questions or concerns: open an issue at github.com/lcajigasm/omega/issues.
