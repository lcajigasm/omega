Privacidade

O omega é uma ferramenta de linha de comandos e uma app de secretária. Ambas correm na tua máquina. Não tem conta, nem servidor próprio, nem analítica, nem telemetria. Este site não define cookies; quando escolhes um idioma, guarda a escolha no teu navegador.

O que fica na tua máquina

As tuas chaves de API ficam guardadas no porta-chaves do macOS, no serviço omega-cli. No Windows, ficam guardadas no Gestor de Credenciais. No Linux, ficam guardadas no porta-chaves do sistema (Secret Service) ou, quando não há nenhum, em ~/.config/omega/keys, um ficheiro que só o teu utilizador pode ler. A tua configuração está em ~/.config/omega/config.toml, as notas que o agente guarda sobre a tua máquina em ~/.config/omega/notes.md e um registo de cada execução em ~/.local/state/omega/runs. Podes apagar qualquer um deles quando quiseres.

O que vai para o teu fornecedor de IA

O omega fala apenas com o fornecedor que configurares: Anthropic, OpenAI, OpenRouter ou OpenCode Zen. Cada pedido contém as instruções do omega, as tuas notas, a saída abreviada dos comandos que executou e o conteúdo dos ficheiros de configuração que leu. O agente tem instruções para não ler documentos pessoais. A esses pedidos aplicam-se a política de privacidade e os termos de retenção de dados desse fornecedor.

O catálogo de modelos

Para escolher os modelos do modo automático, o omega descarrega a lista pública de modelos da OpenRouter de openrouter.ai uma vez por dia, mesmo quando o teu fornecedor é outro. É um pedido simples, sem chave e sem nada sobre ti ou a tua máquina; a OpenRouter pode registar o teu endereço IP ao servi-lo. omega config set model_catalog off desativa-o, e os fornecedores locais nunca o fazem.

A verificação de versão

omega doctor pede ao GitHub (api.github.com) a etiqueta da versão mais recente do omega, para te avisar quando a tua é mais antiga. O pedido não leva nada sobre ti; o GitHub pode registar o teu endereço IP. Nenhum outro comando o faz.

Este site

Este site está alojado no GitHub Pages e carrega tipos de letra do Google Fonts, ícones do unpkg e, na página inicial, o leitor de sessões do jsDelivr. Esses serviços podem registar o teu endereço IP ao servirem os ficheiros.
